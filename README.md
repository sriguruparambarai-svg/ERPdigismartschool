---

## Step 1 — Set up Supabase Database

1. Go to https://supabase.com → Log in
2. Open your project: **digismartschool**
3. Click **SQL Editor** in the left menu
4. Open the file `setup-db.sql` from this folder
5. Copy all the SQL and paste it into the SQL Editor
6. Click **Run** — your database table is ready!

---

## Step 2 — Deploy to Vercel

1. Upload this entire folder to GitHub
2. Go to https://vercel.com → New Project → Import from GitHub
3. Click Deploy — done!

Or drag-and-drop the folder to Netlify.
