🔒 Parent PINs
Parents log in with the child's roll number and this 4-digit PIN. Give each slip only to the parent — not in the diary. A PIN is shown only once, when it is made, so print the slips straight away. Until a child has a PIN, the date of birth still works for that child.

Parent Forgot PIN or Password
Find the child, then give the parent a new PIN. Any password the parent chose is removed, so the new PIN works.
